## 🌟 نبذة عن المنصة (Platform Overview)

منصة **"المعلم العربي المحترف"** هي منصة برمجية تعليمية متكاملة (EdTech SaaS) صممت خصيصاً لتلبية احتياجات المعلمين والمدارس والمشرفين والطلاب في العالم العربي، مع التركيز على دعم المناهج العربية والمنهج اليمني بشكل أصلاني.

تدمج المنصة بين أحدث تقنيات **الذكاء الاصطناعي السيادي (Gemini 2.5 API)** وفلسفة **"المعلم الهادئ المستقل (Mindful Educator)"** التي توازن بين استخدام التقنية الحديثة كمساعد ذكي وبين الحفاظ على أصالة التعليم المباشر والتفاعل الصفّي الملموس.

## 🚀 المراحل الخمس للتطوير الشامل (Development Phases)

### 1️⃣ المرحلة الأولى: البنية الأساسية المحسّنة (Infrastructure & Core)
- دعم كامل للغة العربية (RTL) والتفاعل بالإنجليزية.
- واجهة أكاديمية راقية تعتمد الألوان الذهبية الملكية (`#C5A021`) والأزرق الكحلي الأكاديمي (`#1A365D`).
- خادم خلفي متكامل (Express + Vite Proxy) يحمي مفاتيح الأمان في البيئة الخلفية (Server-Side Execution).

### 2️⃣ المرحلة الثانية: المكتبة المنهجية الذكية (RAG Curriculum Engine)
- محرك استرجاع مدعم بالتوليد (RAG) يربط نماذج الذكاء الاصطناعي بنصوص المناهج والكتب المنهجية الرسمية وندليل المعلم.
- دعم الفهرسة والبحث النصي الفوري في كتب المواد والصفوف الدراسية المختلفة.

### 3️⃣ المرحلة الثالثة: أدوات المعلم الاحترافية (Teacher Productivity Tools)
- **مخطط الدروس الذكي:** توليد أهداف دراسية، واستراتيجيات، وأنشطة صفية، وواجبات جاهزة للطباعة.
- **مولد العروض التقديمية (PPTX Generator):** إنشاء شرائح بوربوينت احترافية منسقة تلقائياً مع خيارات التنزيل المباشر.
- **بنك الأسئلة والمستندات:** توليد أسئلة موزونة حسب مستويات بلوم للفيزياء والكيمياء واللغة العربية والإسلاميات وغيرها.
- **أوراق العمل وتصاميم الأنشطة:** أدوات لإنشاء أنشطة كتابية وتفاعلية.
- **المساعد الصوتي والملخص الذكي:** تلخيص الكتب الصوتية والملفات وسحب النقاط الرئيسية.

### 4️⃣ المرحلة الرابعة: إدارة الفصول والطلاب والتحليل (School & Class Management)
- **إدارة الفصول والحضور:** إضافة الفصول، تسجيل الحضور والغياب، ومتابعة السلوك وسجل الدرجات.
- **بوابة الاختبارات والتصحيح الإلكتروني:** تمكين الطلاب من أداء الاختبارات عبر الإنترنت والتصحيح الآلي الفوري مع تقارير التغذية الراجعة.
- **لوحة المشرف والتحليلات الذكية:** رسوم بيانية لإحصائيات الأداء الأكاديمي وإشارات الإنذار المبكر للطلاب المتأخرين.
- **رسائل أولياء الأمور:** توليد رسائل محترفة ومخصصة بالذكاء الاصطناعي لإرسالها عبر الواتساب أو البريد.

### 5️⃣ المرحلة الخامسة: التحول التجاري وإدارة SaaS (Commercial SaaS Transformation)
- **خطط الاشتراكات الثلاثية:**
  - **الخطة المجانية (Free Explorer):** 15 تجربة شهرياً مع إمكانية إدارة فصلين.
  - **خطة المعلم المحترف (Pro Teacher):** توليد غير محدود، تصدير PPTX، وتصحيح إلكتروني.
  - **خطة المدارس والمؤسسات (School Enterprise):** ترخيص مؤسسي وشبكة حسابات متعددة.
- **نظام كروت وشفرات التفعيل:** توليد قسائم اشتراك وتفعيل الأكواد فورياً للمعلمين والمدارس.
- **سجلات المراقبة والأمان (System Audit & Error Logs):** تسجيل عمليات الذكاء الاصطناعي ومتابعة أي استثناءات في السيرفر.
- **طبقة التخزين المؤقت (In-Memory Response Caching):** تسريع عمليات الاستجابة بمتوسط 1.2 ثانية وحفظ رصيد الذكاء الاصطناعي.
- **النسخ الاحتياطي والاستعادة (Data Backup & Restore):** تصدير واستيراد بيانات الفصول والاختبارات بصيغة JSON آمنة.
- **صفحة الهبوط والشروط القانونية:** صفحة تعريفية تجارية وبوابة كاملة لسياسة الخصوصية وسجل الملكية الفكرية.

### 6️⃣ المرحلة السادسة: المناهج الإقليمية والتخزين المحلي والترجمة (Regional Curriculum, Offline & i18n)
- **محرك المناهج الإقليمية المعتمدة (Regional Curricula Engine):** دعم مناهج متعددة (اليمن، السعودية، مصر، الإمارات، الأردن، المنهج العربي العام) مع التكيف التلقائي لأوامر الذكاء الاصطناعي مع وزارة التعليم النشطة.
- **نظام التدوين والترجمة الشامل (i18n & Directionality):** دعم كامل للغة العربية بوضع RTL واللغة الإنجليزية بوضع LTR مع سهولة التوسع لتقبل لغات جديدة مستقبلاً.
- **وضع العمل بدون اتصال (Offline PWA & Local Cache Storage):** حفظ التحضيرات وأوراق العمل والأسئلة محلياً في IndexedDB/LocalStorage مع المزامنة التلقائية عند عودة الاتصال.

## 🛠️ البنية التقنية (Tech Stack & Architecture)

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide React Icons, Motion (Framer).
- **Backend:** Express.js, Node.js, TSX (TypeScript Execution).
- **AI Integration:** Google GenAI SDK (`@google/genai`), Gemini 2.5 Flash Model with Server-side Proxy & Retry mechanisms.
- **Exporting Modules:** `pptxgenjs` (PowerPoint generation), Client-side JSON Backup/Restore.

## 📡 أهم نقاط النهاية البرمجية (Core API Routes)

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `/api/curriculum/chat` | `POST` | RAG-based AI chat with curriculum text context |
| `/api/classrooms` | `GET / POST` | Manage classrooms and student lists |
| `/api/quizzes/generate` | `POST` | AI Online Quiz Generation |
| `/api/quizzes/submit` | `POST` | Student Quiz Auto-Grading & Feedback |
| `/api/subscriptions/plans` | `GET` | Fetch available SaaS subscription tiers |
| `/api/subscriptions/upgrade` | `POST` | Redeem voucher codes & upgrade subscription |
| `/api/admin/logs` | `GET` | View real-time system audit & security logs |
| `/api/admin/backup` | `GET` | Export full application JSON state backup |
| `/api/admin/restore` | `POST` | Restore full application database state |

## 💻 التشغيل والإطلاق (Running & Deployment)

1. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   ```

2. **التشغيل التجريبي (Development Server):**
   ```bash
   npm run dev
   ```
   *يعمل السيرفر على المنفذ `http://localhost:3000`*

3. **بناء النسخة الإنتاجية (Production Build):**
   ```bash
   npm run build
   ```

4. **التشغيل الإنتاجي (Production Start):**
   ```bash
   npm start
   ```
